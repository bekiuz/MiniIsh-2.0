# MiniIsh 2.0

Kichik topshiriqlarni e’lon qilish va kuzatish g‘oyasi uchun boshlang‘ich, brauzerga asoslangan task-board prototipi.

## Hozirgi imkoniyatlar

- Topshiriq sarlavhasi, tavsifi, turi va budjetini kiritish.
- Topshiriqlarni nomi yoki tavsifi bo‘yicha qidirish.
- Topshiriq turiga qarab filtrlash.
- Ochiq va bajarilgan holatlarni almashtirish.
- Jami, ochiq va bajarilgan topshiriqlar sonini ko‘rsatish.
- Topshiriqni tasdiq bilan o‘chirish.
- Ma’lumotlarni brauzerning `localStorage` xotirasida saqlash.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylashtiring. Build vositasi yoki API kaliti talab qilinmaydi.

## MVP chegaralari

Bu hali haqiqiy ko‘p foydalanuvchili ish bozori emas. Ro‘yxatlar faqat joriy brauzerda saqlanadi; ro‘yxatdan o‘tish, buyurtmachi va ijrochi akkauntlari, chat, to‘lov, moderatsiya va server sinxronlash yo‘q.

## Keyingi bosqich

- Buyurtmachi va ijrochi rollari.
- Topshiriq yuborish va ariza bildirishnomalari.
- Xavfsiz backend, autentifikatsiya va moderatsiya.
- Kelishuv, baholash va nizolarni ko‘rib chiqish jarayoni.
